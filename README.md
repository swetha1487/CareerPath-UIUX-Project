# CareerPath — Student Career & Internship Finder

A responsive UI/UX project for the Tamizhan Skills RISE Internship, Project 2: Industry-Oriented UI/UX Design for a Responsive Web Application.

## How to open
1. Extract the ZIP folder.
2. Open `index.html` in Chrome, or open the folder in VS Code and use Live Server.
3. Resize the browser or open DevTools mobile emulation to test responsive layouts.

## Screens / user journeys
- Home dashboard with search and featured internship cards
- Internship search results with keyword, location, type and beginner filters
- Internship details with skills and a demo-only Apply button
- Career Skills page
- My Profile demo page
- Mobile navigation and responsive layouts

## Prototype notes
The prototype is interactive and front-end only. The listings are sample data, not live vacancies. The Apply button does not submit a real application. The profile is not sent to a server.

## Figma handoff
Import the included `assets/design-system.svg` and `assets/wireframe-map.svg` into Figma as reference boards. You can also take screenshots of the browser prototype and place them in your Figma file. For the internship submission, make sure to save the frames and connect the screens using Figma Prototype mode if a native Figma prototype link is required.

## Accessibility / usability considerations
- Semantic headings and labels
- Keyboard-accessible buttons and links
- Responsive layout for smaller screens
- Clear contrast and readable type
- Status messages for demo actions
- Filters have visible labels

## Suggested submission contents
1. This report and README
2. Screenshots of desktop and mobile
