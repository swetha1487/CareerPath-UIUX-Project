# CareerPath — Student Career & Internship Finder
## UI/UX Design Project Report
**Program:** Tamizhan Skills RISE Internship — UI/UX Design  
**Project:** Industry-Oriented UI/UX Design for a Responsive Web Application  
**Tool:** Figma (design handoff) and HTML/CSS/JavaScript (interactive demonstration)

## 1. Abstract
CareerPath is a responsive web application concept that helps students discover internship opportunities and explore career skills. It provides a clear search experience, filters, readable internship details, and responsive layouts for desktop and mobile. The project demonstrates user-centred design through information architecture, wireframe planning, high-fidelity interface styling, interaction design, accessibility considerations, and usability testing.

## 2. Problem Statement
Many web applications are difficult to use across devices, which can cause confusion and prevent users from completing tasks. Students may also find internship information scattered or hard to compare. CareerPath explores a consistent, easy-to-use interface that supports internship discovery on desktop and mobile screens.

## 3. Objective
To design a responsive web application with an intuitive and consistent user experience across desktop and mobile devices.

## 4. Web Application Concept
CareerPath is a student-focused internship finder. It lets users search by role or skill, filter sample opportunities, read internship requirements, explore learning paths, and maintain a simple profile.

## 5. Target Users and Use Cases
**Target users:** college students, freshers, and beginners exploring career options.  
**Use cases:** search for an internship; filter by location or work type; view role details and required skills; explore career learning topics; update a basic profile.

## 6. Information Architecture
- Home
- Find Internships
  - Search results
  - Filters
  - Internship details
  - Apply demo action
- Career Skills
- My Profile

## 7. Wireframe and Screen Plan
**Desktop:** home dashboard, search results with side filters, internship details, career skills, profile.  
**Mobile:** stacked home content, full-width search fields, single-column cards, compact navigation, responsive details view.  
Wireframes should focus on layout and hierarchy before final colours and decorative elements.

## 8. High-Fidelity Design
The visual system uses primary blue (#2563EB), light blue (#EFF6FF), navy (#102A56), dark text (#172033), muted text (#64748B), and white. Cards, buttons, skill tags, spacing, and typography are reused for consistency.

## 9. Responsive Layout Decisions
Desktop uses multi-column cards and a side filter panel. Mobile changes the layout to one column, stacks form fields, reduces page padding, and uses compact bottom navigation. The layout should be tested at desktop and phone widths.

## 10. Accessibility and Usability
- Use clear headings and labels.
- Maintain readable font sizes and strong text contrast.
- Keep navigation consistent.
- Make controls easy to tap on mobile.
- Do not communicate status using colour alone.
- Provide feedback for demo actions.
- Test the main tasks with a classmate and record improvements.

## 11. Interactive Prototype
The included prototype links Home, Search Results, Internship Details, Career Skills, and My Profile. Search and filters update the sample results. Internship cards open details. The Apply button shows a demo notice only. No real application is sent.

## 12. Usability Test Plan
Ask a classmate to: (1) find a UI/UX internship, (2) open the internship details, and (3) identify the required skills. Note any confusion, unclear labels, or difficulty on mobile. Improve the interface based on feedback. Do not claim user testing was completed unless it has actually been done.

## 13. Expected Outcome
A portfolio-ready responsive UI/UX concept with screen layouts, a design system, a clickable demonstration, accessibility considerations, and documentation. The HTML prototype is a demonstration aid; a native Figma file and Figma prototype share link should be created in the student's Figma account if explicitly required for submission.
